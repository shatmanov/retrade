<h1 align="center">ReTrade</h1>

<p align="center"><strong>Показывает ценность карт ReManga для обмена.</strong></p>

Бесплатное расширение для Chrome с настраиваемыми списками ценности карт.

> **Важно:** ReTrade — независимый сторонний проект. Он не является официальным расширением ReManga и не одобрен администрацией ReManga.

## Возможности

- Показывает ценность карт непосредственно на карточках ReManga.
- Поддерживает несколько списков обмена.
- Позволяет переключать активный список через popup.
- Позволяет изменять существующие списки и добавлять собственные.
- Поддерживает категории **Прем**, **Полупрем**, **Полуторник** и **Ивентовые**.
- Обрабатывает динамически загружаемые карточки и бесконечную прокрутку.
- Настройки списков находятся в `src/config.js`.

## Как это работает

ReTrade использует API-ответы, которые уже получает сам сайт ReManga, и не создаёт отдельные запросы только ради получения данных о карточках.

Расширение:
1. получает API-ответ;
2. определяет карточки;
3. сопоставляет их с выбранным списком;
4. определяет категорию ценности;
5. добавляет статус на карточку;
6. обрабатывает новые карточки, появившиеся при прокрутке.

## Настройка списков

Главный файл:

```text
src/config.js
```

Менять `content.js`, `interceptor.js` или `popup.js` для добавления списка не требуется.

Можно редактировать существующий список или добавить новый.

### Формат списка

```js
slugname: Object.freeze({
    label: "name",

    statuses: Object.freeze({

        // Прем
        xxx: "premium", // Название тайтла

        // Полупрем
        xxx: "semi-premium", // Название тайтла

        // Полуторник
        xxx: "one-and-half", // Название тайтла

        // Ивентовые
        xxx: "event", // Название тайтла
    })
})
```

Пример:

```js
robin-hood: Object.freeze({
    label: "РобинГуд",

    statuses: Object.freeze({

        // Прем
        12345: "premium", // One Piece

        // Полупрем
        67890: "semi-premium", // Naruto

        // Полуторник
        54321: "one-and-half", // Bleach

        // Ивентовые
        98765: "event", // Attack on Titan
    })
})
```

### `slugname`

Техническое имя списка.

Рекомендуется:
- только латиница;
- цифры разрешены;
- без пробелов;
- без кириллицы;
- без специальных символов;
- для нескольких слов использовать `-`;
- имя должно быть уникальным.

Хорошо:

```text
robin-hood
premium-2026
my-exchange-list
```

Не рекомендуется:

```text
Robin Hood
РобинГуд
my_exchange_list
my/list
my list
```

### `label`

Отображаемое имя списка:

```js
label: "РобинГуд",
```

Именно оно будет показано пользователю в popup.

### ID тайтла

Ключ внутри `statuses` — это **ID тайтла ReManga**:

```js
12345: "premium",
```

`12345` используется расширением для сопоставления.

Название после `//` — только комментарий для удобства:

```js
12345: "premium", // One Piece
```

Рекомендуется всегда указывать название тайтла в комментарии.

### Значения статусов

| Значение | Отображение |
|---|---|
| `premium` | Прем |
| `semi-premium` | Полупрем |
| `one-and-half` | Полуторник |
| `event` | Ивентовые |

## Добавление своего списка

В `STATUS_SETS` добавьте новый объект:

```js
my-list: Object.freeze({
    label: "Мой список",

    statuses: Object.freeze({

        // Прем
        11111: "premium", // Название тайтла

        // Полупрем
        22222: "semi-premium", // Название тайтла

        // Полуторник
        33333: "one-and-half", // Название тайтла

        // Ивентовые
        44444: "event", // Название тайтла
    })
}),
```

После добавления список автоматически появляется в popup.

## Установка

1. Скачайте исходный код или готовый архив из [Releases](../../releases).
2. Распакуйте архив.
3. Откройте `chrome://extensions/`.
4. Включите **Режим разработчика / Developer mode**.
5. Нажмите **Загрузить распакованное расширение / Load unpacked**.
6. Выберите папку, содержащую `manifest.json`.
